Laboratory 03

Biodiversity

Analyse species abundance, community composition, alpha and beta diversity, richness and ecological community structure.

Community data

One species and its observed count per row.

Accepted: CSV with a header and two columns (species, abundance), or tab-separated values.
Chao1 uses the number of singleton and doubleton species. It estimates unseen richness; it is not a direct count of species.

Community analysis

Observed diversity and estimated richness

Indices are calculated from the abundance counts supplied. Sampling design, taxonomic resolution and sampling effort affect ecological interpretation. This MVP does not yet calculate sample-based Chao2, ACE, rarefaction or confidence intervals.

Two-community taxonomic similarity & dissimilarity

Compare taxon composition and abundance between two communities. Each index is reported independently.

Beta diversity

Community comparison data

Enter one taxon per row with its abundance in each community. Use zero when absent.

Required columns: Taxon, Community A, Community B. Include shared and unique taxa; counts must be non-negative integers.

Independent index results

Run the comparison to calculate taxonomic indices.

Enter both community abundance columns and select “Compare communities”. Similarity and dissimilarity values are calculated separately.

Customisable comparison table

Choose count, relative-abundance or presence/absence values; sort rows and adjust numeric precision.

The comparison table will appear after analysis.

Customisable graphs

Build abundance or index comparison plots. The combo chart displays Community A as bars and Community B as a line.

All graph settings can be changed independently. For an index plot, values are on a 0–1 scale. Similarity is higher when communities are more alike; dissimilarity is higher when they differ more.

Interpretation: presence/absence indices treat all recorded taxa equally; abundance-based indices also use counts. Compare communities with consistent sampling effort, taxonomic resolution and identification. Similarity and dissimilarity indices describe compositional resemblance, not ecological cause.

Community structure

Rank-abundance patterns, beta diversity, abundance-distribution models and chi-square goodness-of-fit.

Dedicated module

Single-community abundance

One taxon and count per row.

Rank-abundance curve

Run analysis to view the curve and interpretation.

Multi-community abundance matrix

Rows are taxa; columns are communities. Use zero when absent.

At least two community columns; non-negative abundances only.

Pairwise beta-diversity results

Jaccard, Sørensen and Bray–Curtis dissimilarity for every pair.

Enter a community matrix and calculate beta diversity.

Goodness-of-fit test

Test equal expected abundance among observed taxa.

H₀: all observed taxa have equal expected abundance. This is a specific null model.

Observed versus expected abundance

Run the test to view statistic, p-value and interpretation.
Interpret with representative sampling, comparable effort and consistent taxonomy. The chi-square approximation can be unreliable when expected counts are too small; consider justified pooling or an exact / simulation-based method.
