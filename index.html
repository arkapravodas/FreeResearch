Interpretation: presence/absence indices treat all recorded taxa equally; abundance-based indices also use counts. Import or build a community abundance matrix

Upload an Excel workbook (.xlsx) or CSV file, paste a matrix, or edit the table directly. Rows represent taxa; columns represent sampling groups / communities; cells contain non-negative abundance counts.

For Excel, the first worksheet is imported. Header row should contain Taxon followed by community/group names.

Calculated columns such as ni, pi, ln(pi), pi×ln(pi), H′, Hmax, lnS and Pielou evenness are recognised as derived fields and excluded from the abundance matrix. Summary rows such as S, N and N/S are also excluded. Check the selected community columns before calculating.

Editable abundance table

Click any cell to edit. Add or remove taxa and community columns as needed.

Taxon-level Shannon contribution table

Zero-abundance taxon-community combinations are shown with pi = 0 and ln(pi) / pi×ln(pi) left blank; they contribute zero to H′. The table uses raw abundance counts and recalculates proportions separately within each community.
