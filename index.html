Laboratory 01

Mathematical Modelling

Simulate continuous-time systems using a fourth-order Runge–Kutta (RK4) numerical solver. Choose a model, adjust parameters and inspect trajectories.

Model configuration

Select a system and define its parameters.

Smaller steps generally improve numerical resolution but take longer.
Using RK4 integration. Results are generated locally.

Laboratory 02

Biostatistics & Biodiversity

Paste or enter a species-abundance table to calculate alpha-diversity indices and non-parametric richness estimates.

Community data

One species and its observed count per row.

Accepted: CSV with a header and two columns (species, abundance), or tab-separated values.
Chao1 uses the number of singleton and doubleton species. It estimates unseen richness; it is not a direct count of species.

Community analysis

Observed diversity and estimated richness

Indices are calculated from the abundance counts supplied. Sampling design, taxonomic resolution and sampling effort affect ecological interpretation. This MVP does not yet calculate sample-based Chao2, ACE, rarefaction or confidence intervals.

Planned modules

The dashboard currently provides working mathematical modelling and biodiversity analysis tools. Other modules are roadmap placeholders, not active calculation engines yet.

  • QM/MM learning utilities and molecular structure visualisation
  • Docking result visualisation and MD trajectory analysis
  • Primer design, reverse complement and ePCR utilities
  • Virtual agarose/PAGE gel and Southern/Western blot studio
  • Ant colony optimisation and genetic algorithm visualisation
  • Bayesian inference, sampling, rarefaction and multivariate statistics
  • EasyQGIS-style spatial analysis
